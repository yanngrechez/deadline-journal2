# Language selector

The published release uses the cached Spanish and French translations approved in the local preview. These translations were drafted by the assistant; they were not generated by DeepL. English is the default. German, Dutch (Netherlands), and Hungarian are shown as disabled future options.

No translation API is connected. New or edited article text is not automatically translated. An article whose current text is not fully covered by the catalog stays in English with a localized notice. CMS publishing continues normally.

`journal-language-data.js` contains the existing translation catalog. Sources are excluded, along with separate author/photo-credit names. Translated navigation keeps the existing canonical URLs and source region data.

Connect a translation service and generate/review complete catalogs before enabling additional locales. Never place an API key in browser assets. The experimental DeepL build integration remains outside this release.
